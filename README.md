# CancerPrediction – Pathology Image Cancer Classifier

This project uses a deep learning model to classify **pathology (microscopy) cell images** as **cancerous** or **non-cancerous**.  
The model is trained on the Kaggle IDC Breast Cancer Histopathology dataset and provides an interface to upload an image and receive a prediction.

⚠️ **This system works only with microscopy/pathology images — not X-ray images.**

---

## 🚀 Features
- Classifies pathology cell images into **Cancer** / **No Cancer**
- Trained using real histopathology slides from Kaggle
- Multiple model checkpoints (`.pth`) included
- Web interface (Flask) for uploading and predicting
- Training + testing scripts provided for reproducibility
